# 1. Use camelCase for variable names. Start variable names with a lowercase letter and capitalize each subsequent word.
# 2. Use meaningful, descriptive names. Avoid vague single-letter names (except i or j in standard loops) so the code explains itself.
# 3. Indent code blocks with 4 spaces. Every block inside curly braces {} must be indented by 4 spaces (never mix tabs and spaces).
# 4. Write one statement per line. Never chain multiple declarations or assignments on a single line.
# 5. Comment the purpose of code blocks. Write brief // comments above logical sections (input, calculation, output) rather than stating the obvious.
